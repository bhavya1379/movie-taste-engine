# Movie Taste Engine

A movie app where you like or dislike titles and it recommends more based on your taste.

![Screenshot](screenshot.png)

## Features
- Search and genre filter
- Movie detail page (React Router)
- Like / dislike with localStorage persistence
- Taste profile showing favourite genres
- "For You" list (liked genre +2, disliked genre -1, then sorted)
- Watchlist and side-by-side compare

## Tech
React, Vite, React Router, Context API

## Run locally
npm install
npm run dev
